# Excel Business Insights and Sales Analytics

## 📌 Overview
An interactive Excel dashboard project for analyzing sales data and generating business insights using data visualization techniques.

## 🚀 Features
- Interactive Dashboard
- Sales Analysis
- Profit Analysis
- KPI Metrics
- Pivot Tables & Charts
- Dynamic Filters and Slicers
- Business Insights Visualization

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📊 Insights Generated
- Total Sales & Profit
- Top Performing Products
- Regional Sales Performance
- Monthly Sales Trends
- Customer Purchase Analysis

## 🎯 Objective
To transform raw sales data into meaningful insights and visually appealing reports for better decision making.
